TaskFlow 🚀
A modern, responsive, and feature-rich web-based project and task management application built with vanilla JavaScript, HTML5, CSS3, and Firebase. Designed to help individuals and teams organize projects, track workflows efficiently using interactive Kanban boards, and monitor progress through visual analytics.

✨ Key Features
Secure Authentication: User sign-up and sign-in functionality powered by Firebase Authentication with real-time session management and profile display.

Project Management: Create, view, and delete projects seamlessly with dedicated project cards and custom dashboards.

Interactive Kanban Board: Manage tasks dynamically across To Do, In Progress, and Done columns using intuitive drag-and-drop mechanics.

Real-time Database: Instant synchronization of projects and tasks using Firebase Realtime Database.

Reports & Analytics: Comprehensive visual reports featuring Bar and Pie charts (powered by Chart.js) to monitor task distribution and project-wise progress.

Responsive UI/UX: Clean, modern sidebar layout built following modern design guidelines for a seamless user experience.

🛠️ Tech Stack
Frontend: HTML5, CSS3, JavaScript (ES Modules)

Backend & Database: Firebase Authentication & Firebase Realtime Database (v12.19.0 via CDN)
